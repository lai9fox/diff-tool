# Diff UI / UX 设计说明

日期：2026-09-29  
依据：[首版需求说明](./requirements.md)  
交付：设计规范 + Astro / Vue 可交互原型

## 1. 已确认的设计决策

- 产品名称 Diff；界面支持简体中文和英文，可随时切换。
- 明暗双主题，默认跟随系统，支持手动选择。
- 首次进入为两个空编辑区，不预填文本，不提供示例入口。
- 采用适中密度；主体为全屏文本工作台，优先电脑。
- 所有比较工具展开，不收进“更多”或设置菜单。
- 默认左右可编辑视图；上下视图为只读合并差异视图。
- 默认自动折行和折叠相同内容，默认关闭忽略行首尾空白。
- 正文只在当前页面内存中保留；仅持久保存界面偏好。
- 工具栏提供“清空全部 / 撤销清空”；页面底部不保留说明、图例或统计栏。
- 类型和行数放在各侧标题旁，空白时不显示统计。

## 2. 设计概念与自检

设计主题是“看清同一处变化”。以连贯的双栏文本面板为主体，用对齐、行号、增删符号、两级高亮建立对应关系。产品识别来自紧凑的 Diff 字标与减号、加号组成的标记。

### 设计原则

1. 文本优先：工具区保持紧凑，把主要高度和宽度交给正文。
2. 颜色有含义：蓝色表示操作与定位，绿色表示新增，玫红表示删除。
3. 状态可见：布局、比较规则、当前位置不藏在菜单里。
4. 编辑可预期：展示开关不改正文，编辑与清空均可撤销。
5. 信息左对齐：工具、标题、文本从稳定的左侧基线开始；局部空白引导置于编辑区中。

### 设计自检与调整

最初可将低频工具收入菜单，但用户要求全部展开，因此采用两行固定工具区。第一行放布局、差异导航、语言和主题；第二行展开比较选项及清空操作。

对比产品需要的是连续的文本空间，因此取消装饰性卡片、介绍区和重复标题。个性集中在 Diff 标记和差异的视觉层次，避免让装饰颜色与增删语义竞争。空白状态用明确的输入指引；不加入示例入口。

## 3. 视觉规范

### 3.1 基础颜色

| 语义 | 浅色主题 | 深色主题 |
| --- | --- | --- |
| 页面底色 | `#F5F7FA` | `#171B22` |
| 编辑面板 | `#FFFFFF` | `#202631` |
| 主要文字 | `#222B38` | `#E2E8F2` |
| 主要操作 / 焦点 | `#325DC9` | `#91AAFF` |
| 新增标识 | `#177553` | `#75CFAB` |
| 删除标识 | `#B14158` | `#F29DB0` |

衍生规则：边框使用低对比中性色；差异行使用浅色语义底纹，具体改变的字符用更强一层底纹。不要把整列染成新增或删除色。新增与删除始终配合符号表达。

### 3.2 字体与尺寸

| 元素 | 字体 | 起始规格 |
| --- | --- | --- |
| Diff 字标 | 系统无衬线 | 23px，粗体，略收紧字距 |
| 工具、标签 | 系统无衬线，中文优先苹方 | 12–13px，中等字重 |
| 编辑正文 | 本地打包的 JetBrains Mono，中文使用系统回退 | 14px / 22px |
| 空白引导标题 | 系统无衬线 | 17px / 26px |
| 空白引导说明 | 系统无衬线 | 13px / 22px |

代码与中文文案共用稳定行高，便于双侧对齐。字体随应用提供，不请求外部字体服务。

### 3.3 间距与形状

- 使用 4、8、12、16、24、32px 间距级别。
- 控件高度约 32–36px，主要按钮保留文字标签。
- 控件圆角约 6px，整体工作区圆角约 10px，层级不同使用不同形状。
- 分隔线用于区分工具区和面板；不用重复卡片或大面积阴影。
- 动效仅用于交互反馈；尊重减少动态效果偏好。

## 4. 页面布局

### 4.1 桌面左右视图

```text
┌─────────────────────────────────────────────────────────────────────┐
│ [−+] Diff   [左右对比 | 上下对比]     2 / 8 处 [↑][↓]   [语言] [主题] │
│ [✓ 折行] [✓ 折叠相同内容] [忽略行首尾空白]              [清空全部] │
├──────────────────────────────────┬──────────────────────────────────┤
│ 原文 JSON 128 行  [打开文件][复制]│ 修改后 JSON 130 行 [打开文件][复制]│
├──────────────────────────────────┼──────────────────────────────────┤
│ 行号   原文                      │ 行号   修改后                    │
│   −    删除内容                  │   +    新增内容                  │
│        展开相同内容              │        展开相同内容              │
│                                  │                                  │
└──────────────────────────────────┴──────────────────────────────────┘
```

- 使用视口高度布局；文本区内部滚动，顶部操作始终可见。
- 左右初始等宽，首版无需拖动分隔线。
- 两侧标题用中性文字，附减号 / 加号标记帮助理解方向。
- 文件操作与复制位于各自标题栏，作用范围一眼可见。
- 类型与行数紧随侧别标题排列，字号低于标题；窄屏允许换行。编辑区底部不放置统计或说明。
- 顶部差异数量与上下箭头聚合为一组，显示数字时采用等宽数字，避免跳动。

### 4.2 上下视图

- 保留顶部工具和两侧文件操作，使布局切换不改变操作位置。
- 主体变成单个只读视图，删除内容出现在对应新增内容上方。
- 仅显示“只读”和“返回编辑”，不重复解释切换方式。
- 原文和修改后仍分别可以复制；没有合并、接受或拒绝修改按钮。

### 4.3 窄屏

- 工具栏按组换行，不通过隐藏工具来压缩空间。
- 两侧标题栏动作可换行，文本保持可读的最低字号。
- 用户可以选择上下视图阅读；不在窗口缩小时擅自切换用户当前视图。
- 页面可纵向滚动，避免固定高度把操作挤出可达区域。

## 5. 主要用户流程

### 5.1 首次进入与输入

1. 进入页面后两侧为空，状态为“等待输入”。
2. 两侧显示“粘贴原文 / 粘贴修改后文本”，下方只保留“或拖入文件”；“打开文件”入口始终存在。
3. 点击空编辑区即可输入或粘贴，空白引导随正文出现而消失。
4. 输入后立即进入比较流程，用户无需点击开始按钮。
5. 只有一侧非空时，将其与空文本比较，不阻止用户继续操作。

### 5.2 定位与修改

1. 比较完成后显示差异数量，当前差异有可辨识的位置反馈。
2. 使用上一处 / 下一处导航，跳转到差异所在区域。
3. 大段相同文本默认收起；点击折叠提示可展开局部，取消顶部选项可展开全部。
4. 在左右任一侧编辑，差异随输入更新；编辑焦点不丢失。
5. 当前侧复制按钮复制完整正文，不带行号、折叠提示或差异符号。

### 5.3 清空与恢复

1. 工具栏右侧提供“清空全部”，使用普通文字按钮，与左侧比较选项分组排列；两侧为空时禁用。
2. 点击后直接清除两侧正文、文件名和差异结果，不弹窗；保留主题、语言、布局及比较选项。
3. 按钮原位变为“撤销清空”，顶部状态为“已清空”。撤销不定时消失。
4. 点击“撤销清空”可一次恢复两侧正文、文件名、类型与行数。
5. 用户编辑或成功导入新内容后，旧的清空快照失效，入口恢复为“清空全部”。
6. 快照只存在于内存，刷新后不保留。

## 6. 状态与反馈

| 状态 | 表现 | 用户后续操作 |
| --- | --- | --- |
| 初始为空 | 等待输入；两侧输入指引；导航和无内容复制不可用 | 粘贴、输入或打开文件 |
| 已清空 | 两侧为空，顶部显示“已清空”和“撤销清空” | 恢复两侧或输入新内容 |
| 正在比较 | 状态区显示正在比较，避免显示旧的一致结论 | 可以继续输入 |
| 存在差异 | 差异高亮、数量与导航可用 | 跳转、编辑、切换视图 |
| 无差异 | 中性成功状态“内容一致”，导航不可用 | 继续编辑或复制 |
| 忽略规则下无差异 | 显示“当前比较规则下无差异”，忽略选项保持可见 | 关闭选项检查原始差异 |
| 拖入文件 | 目标半区出现清晰边框和“放开以替换…”提示 | 放开文件导入，离开目标取消 |
| 文件读取失败 | 显示侧别及处理建议，保留已有文本 | 选择可读取的 UTF-8 文本文件 |
| 复制成功 | 对应按钮短暂变为“已复制”，提供状态播报 | 继续操作 |
| 复制失败 | 给出手动选择、复制文本的指引 | 在左右编辑区中手动复制 |

错误使用持久的内联提示，直至用户关闭或再次操作；成功反馈短暂显示，不打断输入。

## 7. 中英文与设置

- 使用同一套结构与翻译键；语言切换不重新加载页面、不重置正文或编辑历史。
- 工具、状态、空白引导、错误、复制反馈、只读提示、折叠提示与无障碍名称均提供翻译。
- 语言选择明确显示“简体中文”和“English”。
- 默认简体中文；用户的主动选择仅作为界面偏好保存。
- 主题提供“跟随系统 / 浅色 / 深色”；系统主题变化在跟随模式下即时生效。
- 布局、折行和折叠选择可保存；忽略比较规则每次新会话默认关闭，避免隐性改变比较语义。

| 中文 | English |
| --- | --- |
| 左右对比 | Side by side |
| 上下对比 | Unified |
| 原文 | Original |
| 修改后 | Modified |
| 打开文件 | Open file |
| 复制 / 已复制 | Copy / Copied |
| 清空全部 / 撤销清空 | Clear all / Undo clear |
| 粘贴原文 | Paste original text |
| 粘贴修改后文本 | Paste modified text |
| 或拖入文件 | or drop a file |
| 自动折行 | Wrap lines |
| 折叠相同内容 | Collapse unchanged |
| 忽略行首尾空白 | Ignore outer whitespace |
| 等待输入 | Waiting for input |
| 内容一致 | Texts match |
| 当前比较规则下无差异 | No differences with current rules |

## 8. 可访问性

- 所有操作可使用键盘，Tab 顺序与视觉阅读顺序一致。
- 焦点有可见边框，图标按钮提供中英文无障碍名称和提示。
- 新增 / 删除同时使用符号、行级底色和字符级底色，不仅依靠红绿颜色。
- 正文和主要控件按 WCAG AA 的普通文字对比度目标设计。
- 只读视图标明只读；不可用操作具有真实 disabled 状态。
- 错误使用 alert，状态反馈使用 polite live region；避免把每次键入全文播报。

## 9. 原型验证与开发边界

原型用于验证真实输入、对比、视图切换、主题、语言、折叠与复制的体验。由 Astro 承载页面、Vue 管理交互，使用 CodeMirror 编辑器与差异视图。

验证至少覆盖：

- 首次进入为空，无示例入口。
- 中文浅色、英文深色两种组合。
- 实际输入后产生差异，左右可编辑，上下只读。
- 比较选项、布局与语言切换不修改正文。
- 清空、撤销清空，以及新输入使撤销入口消失；统计与正文状态一致。
- 窄窗口中的工具与编辑区可达。
- 构建及类型检查通过。

这次交付不代表已经完成所有大文件性能和全部浏览器兼容验收。具体验证结果记录在项目 README 中。

技术参考：[Astro 官方 Vue 集成文档](https://docs.astro.build/en/guides/integrations-guide/vue/)、CodeMirror 安装包随附的类型与实现。
