# Diff 工作台设计说明

界面采用全屏应用布局：页面固定为 100dvh，正文在 Monaco DiffEditor 内滚动。默认左右视图可编辑两侧；选择内联视图或空间不足时，修改后一侧可编辑。两侧输入为空时显示粘贴或拖入文件的提示。

编辑器标题栏提供两侧文件导入、全文复制、差异导航、视图切换和相同内容折叠。设置侧栏提供视图、自动折行、折叠相同内容、忽略行首尾空白和清空 / 撤销清空。窄屏侧栏以抽屉形式出现。底部蓝色状态栏显示差异位置、行统计、光标位置、语言模式、界面语言和主题。

默认纯文本，可手动选择语言对两侧着色，不做自动检测。内置 advanced 差异算法显示行内变化和 overview ruler；正文不上传、不持久保存。支持查找替换、多光标、列选择和 Monaco 原生编辑命令。F7 / Shift+F7、Alt+F5 / Shift+Alt+F5 导航差异，Alt+上 / 下移动行。

浅色编辑器、侧栏、标题栏分别使用 `#ffffff`、`#f3f3f3`、`#dddddd`；暗色分别使用 `#1e1e1e`、`#252526`、`#3c3c3c`；状态栏使用 `#007acc`。外层使用系统字体，编辑器使用 Monaco 默认等宽字体。

当前 Monaco 0.57.0 包缺少可直接用于 ESM 的官方简体中文语言包，外层支持中英文切换，编辑器内部文案暂为英文。正文只在内存中，刷新会清空。
